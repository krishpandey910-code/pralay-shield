Pralay Shield is a robust, full-stack Disaster Management platform built with React, FastAPI, and MySQL. It empowers emergency response through real-time SOS alerts, auto-syncing safe houses, live weather updates, volunteer tracking, and ML-powered incident coordination to help first responders save lives.
Full-Stack Mastery: Seamlessly bridges a modern React frontend with a high-performance FastAPI Python backend.

Real-Time Emergency Response: Features live SOS alerting, instant disaster reporting, and dynamic safe-house tracking to coordinate help when it matters most.

Intelligent Coordination: Integrates machine learning capabilities and live weather monitoring to keep communities ahead of crises.

Production-Ready Architecture: Backed by a secure MySQL relational database schema, cleanly structured dependencies, and robust API routing.
